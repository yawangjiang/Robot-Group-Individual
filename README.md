# Robot-Group-Individual

`yawangjiang` 的 MIT VNAV LAB3、LAB4 个人交付文件，按实验分别整理。

| 实验 | 个人任务 | 交付文件 |
| --- | --- | --- |
| LAB3 Deliverable 1 | ROS quaternion / tf2 / Eigen 旋转转换 | [deliverable_1.txt](lab3/deliverable_1.txt) |
| LAB3 Deliverable 2 | 电机分配矩阵秩分析、二次阻力补偿推导 | [deliverable_2.pdf](lab3/deliverable_2.pdf)（2页） |
| LAB4 Deliverable 1 | 单段最小速度轨迹的 QP、边界条件与最优解 | [deliverables_1_2.pdf](lab4/deliverables_1_2.pdf)（第1–2页） |
| LAB4 Deliverable 2 | minimum-snap 多段约束计数及一般 r 阶推广 | [同一 PDF](lab4/deliverables_1_2.pdf)（第3页） |

各目录包含可编辑 LaTeX 源码、精确符号核算结果和 SHA256 清单。个人文件使用 GitHub 提交账号作为标识。

## 任务来源

- [LAB3 官方要求](https://vnav.mit.edu/labs_2023/lab3/exercises.html)
- [LAB4 官方要求](https://vnav.mit.edu/labs_2023/lab4/exercises.html)

LAB3 的转换题按指定名称提交 TXT，数学题使用排版 PDF；LAB4 的两项个人题合并为一份 PDF。

## 与团队交付的关系

团队源码、仿真视频和 rosbag 位于 [LittleHorseyaya/vnav](https://github.com/LittleHorseyaya/vnav)。本仓库仅整理个人题答案，不包含团队飞行报告或实验成绩。

其他成员仍应按课程要求在各自个人仓库提交其个人交付文件。GitHub 仓库提交与课程平台登记、教师访问权限是分别需要确认的事项。
